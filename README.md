# 🌌 Neon Stack Harmony 3D

[![Play Game](https://img.shields.io/badge/PLAY_NOW-00F5FF?style=for-the-badge&logo=gamepad&logoColor=black)](https://marcuscaiado.github.io/neon-stack-3d/)
[![Arcade Hub](https://img.shields.io/badge/🕹️_Arcade_Hub-FF6B9D?style=for-the-badge)](https://marcuscaiado.github.io/marcus-arcade/)

Hypnotic 3D tower slicing and block stacking web game built with **Three.js** and **Web Audio API**.

---

## 🎮 Gameplay & Features

* **Musical Pentatonic Chords:** Every placed slab composes ascending melodic notes from a pentatonic scale (C, D, E, G, A), creating soothing synth harmonies as you ascend.
* **Precision Slicing Physics:** Overhanging block pieces are cleanly sliced off and fall away with 3D gravitational physics debris.
* **Combo Multipliers:** Perfect alignments trigger glowing combo fireworks and expand your building slab.
* **Instant Play & Zero Lag:** Pure Three.js and procedural Web Audio — zero external asset load times.
* **Fully Responsive:** Optimized for desktop keyboards/mice, touch screens, and tall mobile viewports (Samsung Galaxy A55).

---

## 🕹️ Controls

* **Tap Screen / Click / Spacebar:** Drop & place moving slab.
* **Arcade Hub Link:** Return to Marcus's Web Arcade anytime via top-right button.
